# 角色三评估协议

本协议用于统一角色三所有评估实验的边界条件，保证自动标注审计、YOLO 与开放域模型对比、分割面积分析三个环节的指标可复现、可核对。协议与任务书固定项保持一致。

## 一、固定评估项

| 项目 | 固定要求 |
| --- | --- |
| 测试集 | 200 幅独立测试图像，不参与训练和调参；负样本、难例和小目标分层包含 |
| 检测匹配 | IoU=0.5，报告 Precision、Recall、F1、mAP@0.5 和平均 IoU |
| 公平对比 | YOLO 与开放域模型使用同一测试集、同一 IoU、同一输入分辨率和同一后处理说明 |
| 速度测试 | batch=1，注明硬件、输入分辨率、是否包含预处理和后处理 |
| 分割误差 | 报告掩码 IoU、面积占比误差和至少 3 个失败案例的失败原因 |

## 二、自动预标注协议

预标注采用 GroundingDINO + SAM 组合。GroundingDINO 负责开放域检测框，SAM 以候选框为 box prompt 输出像素级掩码。

| 配置项 | 取值 |
| --- | --- |
| 检测模型 | IDEA-Research/grounding-dino-base（GroundingDINO-B, Swin-B） |
| 分割模型 | facebook/sam-vit-huge（SAM ViT-H） |
| 火焰提示词 | fire, flame, burning, blaze |
| 烟雾提示词 | smoke, smoke plume, heavy smoke |
| 组合提示词 | fire. flame. burning. blaze. smoke. smoke plume. heavy smoke. |
| 检测框阈值 | box_threshold=0.35 |
| 文本阈值 | text_threshold=0.25 |
| NMS 阈值 | 0.7 |
| 输入尺寸 | 1280x1280 |

提示词选择依据：火焰类覆盖明火与燃烧语义，烟雾类覆盖烟柱与浓烟语义，避免使用颜色、材质等与背景强相关的词，降低灯光、夕阳、红色物体误检。阈值与提示词的调参过程记录在 `output/preannotation/run_record.json` 的运行快照中。

后处理流程：先按 box/text 阈值过滤候选框，再按类别做 NMS，把候选框回填原图坐标后送入 SAM 生成掩码，最终输出 YOLO 格式标签与掩码。每次运行的模型名称、版本、阈值、输入尺寸与后处理参数全部保存在运行快照里，保证标注可追溯。

## 三、200 幅双人标注审计协议

角色一与角色二各自独立标注同一 200 幅测试集，角色三负责统计，不参与这 200 幅的标注，避免利益冲突。

一致性口径：

- 标注者 A 与标注者 B 的检测结果按类别做贪婪匹配，IoU=0.5 判定匹配成功；
- 报告 Precision、Recall、F1 与平均 IoU，并按 fire / smoke 分别统计；
- 自动标注分别与 A、B 比对，得到自动标注的准确率、召回率、平均 IoU 与按类别统计；
- 两名标注者分歧较大的框由角色三记录并裁定，裁定规则写入周报。

工时估算口径：人工标注单幅按 90 秒计，自动预标注后人工复核单幅按 25 秒计；节省工时 = 200 x (90 - 25) / 3600 小时，节省比例 = (90 - 25) / 90。两个常数集中在 `config/pipeline.json` 的 audit 段，可按团队实测调整。

## 四、YOLO 与开放域模型对比协议

对比条件固定为：同一 200 幅测试集、同一 IoU=0.5、同一输入分辨率 640x640、同一后处理说明、batch=1 测速。

报告指标：Precision、Recall、F1、mAP@0.5、各类 AP、平均 IoU、FPS。置信度阈值默认 0.25，脚本同时给出使 F1 最大化的阈值作为参考，报告中须写明采用哪个口径。

开放域模型是否微调必须明确说明。为避免与"零样本"表述自相矛盾，建议自动标注与对比使用不同模型或不同提示词配置；若确为同一配置，报告中须注明。

## 五、分割面积与误差协议

对 50 幅测试图像用 SAM 生成像素级掩码，报告掩码 IoU、面积占比误差（预测面积占比与金标准面积占比之差的绝对值）、相对误差与蔓延速率。蔓延速率按相邻时间帧的面积占比差除以时间差计算。至少给出 3 个失败案例，按漏检或欠分割、过分割或误检、边缘粗糙三类归因。

标准时间序列输出为 `segment/frontend_timeseries.csv` 与 `frontend_timeseries.json`，字段为 time、image、area_ratio、mask_iou，直接供角色二前端绘制面积占比趋势曲线。

## 六、可复现要求

- 所有脚本固定随机种子，采样与扰动可复现；
- 每个指标文件都附带运行时刻的配置快照或协议字段；
- 图表、表格、CSV、权重与命令互相对应，最终报告只引用已归档的指标文件；
- 现场演示不把开放域大模型接入实时链路，只运行轻量分割方案。
