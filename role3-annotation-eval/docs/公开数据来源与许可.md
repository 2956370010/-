# 公开数据来源与许可说明

## 已接入的数据源

首选公开数据源为 GitHub 仓库 liuzifan/fire_smoke_datasets：

- 图像数量：约 2,818 张，train/val 分离；
- 标签格式：YOLO 归一化格式，0=fire、1=smoke；
- 图像构成：fire-image_*（约 1,000 张小图）、smoke-image_*（约 1,000 张小图）、fire_smoke_*（约 818 张高分辨率混合场景图）；
- 仓库地址：https://github.com/liuzifan/fire_smoke_datasets 。

该仓库未附带明确许可证声明，仅用于课程学习与研究。若用于公开发布或商业用途，需自行与作者确认授权。

## 备选数据源

任务书中提到的其它公开数据集：

- D-Fire：约 21,000 张，含 fire、smoke、none 三类，标签为 YOLO 格式。官方下载在 OneDrive 与 Kaggle，仓库地址 https://github.com/gaia-solutions-on-demand/DFireDataset 。其中的 none 类可作为负样本来源，但需遵守原始提供方条款（HPWREN、FESB、FireNet 等）。
- FLAME 无人机火情数据集：用于火/非火分类与分割，仓库地址 https://github.com/AlirezaShamsoshoara/Fire-Detection-UAV-Aerial-Image-Classification-Segmentation-UnmannedAerialVehicle 。可提取非火样本作为负样本。

## 下载脚本

- 正常网络环境使用 `scripts/fetch_public_data.py`，可指定 fire/smoke/mixed 数量并把结果写入 `public_data/`；
- 本受限环境使用 `scripts/seed_download.py`（已内置绕过 DNS 劫持的直连地址）。

## 使用注意事项

- 公开数据不能替代任务书要求的自采数据（自采比例不少于总数据量 30%）；
- 负样本（灯光、夕阳、红色物体、雾气和反光）建议自采或从 D-Fire/FLAME 的 none/非火类提取，并在报告中注明来源；
- 下载后先运行 `scripts/public_data_stats.py` 生成统计表，再进行训练/验证/测试划分，避免相邻帧跨集合泄漏。
