# 角色三交付物清单

对照任务书最终验收清单，角色三负责的验收项与对应交付物如下。

| 验收项 | 负责人 | 合格标准 | 角色三交付物 |
| --- | --- | --- | --- |
| 数据与统计 | 角色一/角色三 | 自采比例、类别数量、场景分布、划分和清单可核查 | 与角色一核对后的数据清单、标注规范与测试集说明 |
| 自动标注 | 角色三 | 200 幅双人标注、P/R/IoU、工时估算和修改痕迹齐全 | `output/audit/`、`output/preannotation/run_record.json`、提示词与版本记录 |
| 优化对比 | 角色一/角色三 | 至少一项优化，前后使用同一测试集和同一评估协议 | 对比协议与同集指标脚本 |
| 开放域对比 | 角色三 | 同测试集、同 IoU、同分辨率；说明是否微调和部署成本 | `output/compare/comparison_table.csv`、`comparison_metrics.json` |
| 分割面积 | 角色三 | 掩码、面积占比、蔓延趋势、误差分析和失败案例齐全 | `output/segment/segment_area.csv`、`area_trend.csv`、`error_analysis.md`、图表 |
| 提交材料 | 三人共同 | 源码、报告、视频、权重、数据和说明文档齐全且路径清楚 | 本工程包与报告章节 |

角色三每周交付物：

- 第 1 周：自动标注评估协议、提示词配置与小样本预标注、约 200 幅火烟图像和 100 幅负样本的采集记录；
- 第 2 周：200 幅审计结果、开放域检测对比、50 幅分割面积误差分析，并把图表和标准数据交给角色二；
- 第 3 周：分割面积、蔓延趋势和失败案例分析，自动标注、开放域对比和报告图表定稿。

给角色二的交付接口：

- 面积占比趋势的标准时间序列：`output/segment/frontend_timeseries.csv` 与 `frontend_timeseries.json`；
- 指标图：`output/charts/` 下的 PNG；
- 轻量分割方案、模型路径与调用说明（现场只运行轻量版本，不接入开放域大模型）。
