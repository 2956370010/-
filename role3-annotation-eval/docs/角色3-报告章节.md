# 角色三报告章节

本章节可直接并入设计报告对应位置。带"待填写"字样处为训练机实测值，请运行 `scripts/` 下的脚本后用真实输出替换；公式与口径保持不变。

## 一、大模型自动标注

本环节采用 GroundingDINO + SAM 组合完成开放域预标注。GroundingDINO 依据自然语言提示词输出候选框，SAM 以候选框为 box prompt 生成像素级掩码，最终形成"模型预标注 + 人工校验"工作流。

提示词配置为：火焰类 fire, flame, burning, blaze；烟雾类 smoke, smoke plume, heavy smoke。选择依据是覆盖明火、燃烧语义与烟柱、浓烟语义，同时避免使用与背景强相关的颜色和材质词，以抑制灯光、夕阳、红色物体误检。调参过程见 `output/preannotation/run_record.json`，模型名称、版本、阈值、输入尺寸与后处理参数均在其中记录，保证标注过程可追溯。
