# 给角色二的轻量分割方案

现场演示只在演示笔记本运行轻量版本，不把开放域大模型接入实时链路。开放域检测与高分辨率 SAM 只用于训练机的离线批量推理和对比报告。

## 方案

现场分割采用轻量模型，按关键帧执行，不逐帧推理：

- 模型建议：SAM 的轻量变体，例如 mobile-sam 或 sam-b（ViT-B），输入尺寸 512x512；
- 触发策略：检测到 fire 或 smoke 时，在该视频通道按固定间隔取关键帧做分割，例如每 5 帧分割一次；
- 结果复用：关键帧之间的面积占比用线性插值补全，降低推理压力；
- 输出：每帧输出 area_ratio 与时间戳，直接写入 `output/segment/frontend_timeseries.json` 的时间序列结构，角色二前端按该结构绘图。

## 模型路径与调用约定

- 模型文件放演示笔记本本地，例如 `models/sam/mobile_sam.pt`；
- 调用入口预留为轻量推理函数，输入一帧图像与检测框，输出掩码与面积占比；
- 推理参数记录：输入尺寸 512、box prompt 来源为轻量 YOLO 检测框、后处理阈值固定。

调用示例（示意，具体以角色二接口为准）：

```python
area_ratio = segment_frame(image, boxes, model_path="models/sam/mobile_sam.pt")
```

## 数据契约

角色二只需消费两个标准文件：

- `output/segment/frontend_timeseries.csv`：time,image,area_ratio,mask_iou；
- `output/segment/frontend_timeseries.json`：`{"series": [...], "time_unit": "second"}`。

角色三负责保证这两个文件与离线分析结果一致；现场实时演示时由角色二按同一 schema 写入实时值。
